# freeCodeCamp 平台使用教程

> 适用对象：第一次接触 freeCodeCamp、没有编程基础的学习者  
> 教程目标：登录平台，选择课程，完成并提交第一个编程练习，确认学习进度已经保存。  
> 核对时间：2026 年 7 月。平台可能继续更新，按钮名称和页面布局以实际页面为准。

## 1. 完成本教程后，你应该得到什么

完成下面的操作后，你应该能够：

1. 登录自己的 freeCodeCamp 账号。
2. 找到适合自己的课程。
3. 看懂练习页面的主要区域。
4. 编写并运行第一段代码。
5. 根据测试结果修改代码。
6. 成功提交练习并确认进度。
7. 备份尚未提交的代码。
8. 遇到问题时正确求助。
9. 了解认证证书的基本获取方式。

## 2. 开始前的准备

建议使用电脑完成学习，而不是手机。

开始前准备：

- 一台可以联网的电脑；
- Chrome、Edge 或 Firefox 等较新的浏览器；
- 一个可以长期使用的登录账号；
- 一个用于备份代码的本地文件夹；
- 可选：VS Code、记事本或 GitHub。

建议提前建立下面的目录：

```text
freeCodeCamp学习记录/
├─ HTML与CSS/
├─ JavaScript/
├─ Python/
└─ 学习笔记.md
```

这个目录用于保存重要代码和学习笔记，防止浏览器数据被清理后丢失。

## 3. 进入并登录 freeCodeCamp

### 3.1 打开学习平台

在浏览器地址栏输入：

[https://www.freecodecamp.org/learn/](https://www.freecodecamp.org/learn/)

按下回车键。

正常情况下，你应该看到 freeCodeCamp 的课程学习页面，其中包含网页设计、JavaScript、Python、数据库等学习方向。

如果页面无法打开：

1. 检查其他网站是否可以访问；
2. 刷新页面；
3. 换一个浏览器重新打开；
4. 暂时停用可能拦截脚本的浏览器扩展；
5. 使用浏览器无痕窗口测试。

### 3.2 注册或登录账号

在页面右上角找到登录入口。按钮可能显示为 `Sign in`，也可能显示其他与登录或注册有关的文字。

点击按钮，按照页面当前提供的方式完成登录。不同时间、地区看到的登录方式可能不同，应以实际页面为准。

登录完成后，观察页面右上角：

- 如果能看到头像、用户名或个人菜单，说明已经登录；
- 如果仍然显示 `Sign in`，说明登录没有完成。

以后学习时，应始终使用同一个账号和同一种身份登录。否则可能出现“原来的学习进度不见了”的错觉。

## 4. 选择界面语言

如果页面提供语言选择菜单，可以在其中查找简体中文。

如果部分课程仍然显示英文，这不一定是设置错误。freeCodeCamp 的内容持续更新，翻译进度可能落后于英文内容。

遇到尚未翻译的页面，可以：

1. 暂时切换到英文课程；
2. 使用浏览器的“翻译成中文”功能；
3. 保留代码、标签名、函数名和错误信息的英文原文。

例如：

```html
<h1>Hello</h1>
```

不要把 `h1` 翻译成中文，因为它是 HTML 标签，而不是普通说明文字。

## 5. 认识课程结构

freeCodeCamp 的课程并不只是连续阅读文章。当前课程通常由以下内容组合而成：

| 类型 | 主要作用 | 学习时要做什么 |
| --- | --- | --- |
| Lecture/Theory | 讲解知识 | 阅读并理解示例 |
| Workshop | 跟随步骤制作内容 | 按步骤修改代码 |
| Lab | 独立完成练习 | 根据需求自己编写代码 |
| Review | 复习本模块 | 检查知识遗漏 |
| Quiz | 知识测验 | 选择或填写答案 |
| Exam | 认证考试 | 独立完成考核 |
| Project | 综合项目 | 使用所学知识完成作品 |

freeCodeCamp 官方课程结构采用“认证方向—章节—模块—练习”的层级组织，不同模块会使用 Workshop、Lab、Quiz 等形式。参见 [freeCodeCamp 官方课程结构说明](https://contribute.freecodecamp.org/how-to-work-on-coding-challenges/)。

2025 年课程重组后，一些原来集中在 Full Stack Developer 中的内容也会分区展示；Full Stack v9 汇总入口仍可能存在。因此，不要只根据旧教程截图找课程，应以当前学习页面显示的课程目录为准。参见 [课程重组说明](https://forum.freecodecamp.org/t/curriculum-restructure/767294)。

## 6. 零基础应该先学什么

如果你没有 HTML、CSS 和 JavaScript 基础，建议按照以下顺序学习：

```text
Responsive Web Design
        ↓
JavaScript
        ↓
Front End Libraries
        ↓
Python 或 Back End Development
        ↓
Relational Databases
```

第一次使用时，推荐选择 `Responsive Web Design`。这一方向通常从 HTML 页面结构和 CSS 样式开始，学习结果能够直接在预览窗口中看到。

如果课程旁边出现以下文字，需要注意：

- `Coming Soon`：内容可能尚未全部开放；
- `Beta`：课程仍可能调整；
- `Legacy`：旧版课程，通常保留给已经开始学习旧路径的人；
- `v8`、`v9`：不同版本的课程或认证，进度和证书要求可能不同。

新学习者优先选择当前页面推荐的稳定版本。

## 7. 打开第一个练习

### 7.1 进入课程

在课程列表中点击 `Responsive Web Design`。

进入后，你应该看到：

- 课程名称；
- 章节或模块列表；
- 每个模块中的练习；
- 已完成数量或完成标记；
- 可能出现的认证项目。

打开第一个尚未完成的 HTML 练习或 Workshop。

### 7.2 认识练习页面

练习页面通常包含以下区域，但具体位置可能随课程类型和窗口大小变化：

| 区域 | 用途 |
| --- | --- |
| 任务说明 | 告诉你本步骤要完成什么 |
| 代码编辑器 | 输入或修改代码 |
| 文件标签 | 在多个文件之间切换 |
| 预览窗口 | 查看网页运行效果 |
| 测试结果 | 显示代码是否符合要求 |
| 帮助入口 | 查看提示或在论坛求助 |

如果没有看到全部区域：

1. 向下滚动页面；
2. 缩小浏览器页面显示比例；
3. 展开被折叠的面板；
4. 查看页面底部是否存在运行或检查按钮。

## 8. 完成第一个练习

下面用一个典型 HTML 任务说明操作方法。

假设任务要求：

```text
在页面中添加一个 h1 元素，文字为 CatPhotoApp。
```

### 8.1 只修改任务要求的内容

在代码编辑器中找到需要填写的位置，输入：

```html
<h1>CatPhotoApp</h1>
```

输入完成后，检查：

- 左尖括号 `<` 是否存在；
- 右尖括号 `>` 是否存在；
- 开始标签是否为 `<h1>`；
- 结束标签是否为 `</h1>`；
- 文字大小写是否符合要求。

### 8.2 运行测试

找到页面中的测试按钮。根据练习类型，它可能显示为：

```text
Check your code
```

或者：

```text
Run Tests
```

点击按钮，然后等待测试结果出现。

### 8.3 处理失败测试

如果代码正确，页面通常会显示测试通过信息，或者所有测试项变为绿色。

如果测试失败，不要立即删除全部代码。先阅读第一条失败信息，例如：

```text
You should have an h1 element.
```

它表示页面中没有检测到正确的 `h1` 元素。

重点检查正确写法：

```html
<h1>CatPhotoApp</h1>
```

是否误写成：

```html
<h1>CatPhotoApp<h1>
```

第二种写法缺少结束标签中的 `/`。修改后再次运行测试，直到全部测试通过。

### 8.4 提交练习

当所有测试通过后，按钮可能变为：

```text
Submit and continue
```

点击该按钮。

正常结果是：

1. 当前练习被标记为完成；
2. 页面进入下一步；
3. 课程完成数量增加；
4. 返回目录后，当前练习旁边出现完成标记。

测试通过和正式提交不是同一件事。只有点击提交按钮后，平台才会把该步骤记录为已完成。

## 9. 确认进度已经保存

完成练习后，不要只看“测试通过”，还需要进行一次结果验证。

验证方法：

1. 返回当前课程的目录页；
2. 找到刚才完成的练习；
3. 检查它旁边是否出现勾选、完成颜色或其他完成标记；
4. 记录当前课程的已完成数量；
5. 再次打开刚才的练习，确认它仍显示为已完成。

如果返回目录后没有完成标记，依次检查：

1. 是否只运行了测试，没有点击 `Submit and continue`；
2. 页面右上角是否仍显示已登录状态；
3. 当前登录账号是否和之前相同；
4. 是否进入了另一个课程版本，例如从 v9 进入了 Legacy 版本；
5. 刷新页面后完成标记是否出现。

只有看到课程目录中的完成标记，才算完成本次学习闭环。

## 10. 正确保存和备份代码

freeCodeCamp 中有两种不同的“保存”。

### 10.1 账号中的完成记录

成功提交的练习，其完成状态通常会保存在账号中。以后使用同一个账号登录，仍能看到完成记录。

### 10.2 浏览器中的未提交代码

尚未提交的代码主要依赖浏览器本地存储。运行测试、检查代码或按 `Ctrl+S`，通常会触发本地保存；但清理浏览器数据、更换电脑或提交练习后，本地代码仍可能消失。参见 [2026 年社区保存行为说明](https://forum.freecodecamp.org/t/no-saving-progress-in-labs/783682)。

因此，完成较大的 Lab 或 Project 时，应定期把代码复制到本地文件中：

```text
freeCodeCamp学习记录/
└─ HTML与CSS/
   └─ recipe-page-2026-07-15.html
```

建议每次备份时同时记录：

```text
课程：Responsive Web Design
模块：Basic HTML
练习：Build a Recipe Page
状态：完成第3步，尚未提交
日期：2026-07-15
```

不要把浏览器缓存当作唯一备份。freeCodeCamp 社区说明也明确区分了“账号中的完成记录”和“浏览器中的编辑代码”。参见 [进度与代码保存说明](https://forum.freecodecamp.org/t/can-i-save-my-work-as-i-go-through-the-lessons-i-leave-come-back-and-must-start-all-over-again/674925)。

## 11. 常见问题处理

### 11.1 点击测试按钮没有反应

按以下顺序处理：

1. 先把代码复制到本地文件；
2. 检查是否存在明显的括号、引号或标签错误；
3. 点击页面中的 `Restart Step` 或类似按钮；
4. 按 `Ctrl+F5` 强制刷新页面；
5. 使用无痕窗口重新打开练习；
6. 暂时关闭广告拦截、脚本拦截或深色模式扩展；
7. 更换 Chrome、Edge 或 Firefox 测试。

注意：重置步骤可能删除当前代码，必须先备份。

这些也是 freeCodeCamp 社区处理测试按钮故障时常用的排查方法。参见 [测试按钮故障排查示例](https://forum.freecodecamp.org/t/run-tests-button-not-working/728218)。

### 11.2 测试通过，但不能进入下一步

检查：

- 所有测试是否都已通过；
- 是否出现 `Submit and continue`；
- 是否点击了提交按钮；
- 是否已经登录；
- 刷新后课程目录是否已经显示完成。

如果完成状态已经记录，但页面没有自动跳转，可以直接从课程目录打开下一步。

### 11.3 以前完成的内容显示未完成

可能原因包括：

- 登录了另一个账号；
- 使用了不同的登录身份；
- 进入了不同课程版本；
- 课程更新后新增了练习；
- 当时只通过测试，没有正式提交。

应先确认课程名称和版本，再检查个人资料中的完成记录，不要直接重新学习全部内容。

### 11.4 中文内容不完整

可以切换到英文课程，或者使用浏览器翻译。

代码中的标签、变量名、函数名和错误信息应保留英文。例如：

```javascript
function calculateTotal() {
  return 100;
}
```

不要把 `function`、`return` 等关键字翻译成中文。

## 12. 不会做题时如何求助

先进行以下自查：

1. 重新阅读当前步骤要求；
2. 找到任务中的动作词，例如“添加”“删除”“修改”“放在……内部”；
3. 查看第一条失败测试，而不是一次处理全部错误；
4. 对照上一小步，确认自己只修改了本步骤要求的内容；
5. 检查大小写、空格、引号、括号和标签闭合。

仍然无法解决时，可以打开页面中的 `Get Help`，然后选择类似 `Ask for Help` 的选项。

平台可能会帮助创建一个论坛求助主题，并附带当前挑战链接和代码。你仍然需要补充清楚：

```text
我正在完成：
我希望得到：
实际出现：
第一条失败测试：
我已经尝试：
```

不要只写“为什么不行”。一个有效问题示例：

```text
我正在完成 Build a Recipe Page。

任务要求添加一个 h1 元素，我写的是：
<h1>Recipe Page<h1>

预期测试通过，但系统提示找不到正确的 h1 元素。
我已经检查了文字内容，不确定标签哪里有问题。
```

freeCodeCamp 的求助入口可以把挑战信息和代码带到社区论坛，但学习者仍需补充问题描述并正式发布主题。参见 [求助入口使用说明](https://forum.freecodecamp.org/t/help-me-i-dont-understand-it-man-help-me/771194)。

发布前删除邮箱、密码、Token、真实姓名等私人信息。

## 13. 如何获得 freeCodeCamp 认证

不同课程版本的认证条件可能不同。有的认证要求完成若干项目，有的还包含考试和学术诚信声明。

正确流程是：

1. 进入你正在学习的认证课程；
2. 阅读该课程当前显示的认证要求；
3. 完成全部必修模块；
4. 完成要求中的 Project、Lab 或 Exam；
5. 确认每个必修项目都已提交；
6. 接受学术诚信声明；
7. 打开个人设置或认证页面；
8. 查找 `Claim Certification`；
9. 已领取后，按钮可能显示为 `Show Certification`。

如果不能领取证书，重点检查：

- 是否完成了当前版本的全部要求；
- 是否把 v8 项目用于申请 v9 证书；
- 是否还有考试等待审核；
- 是否接受了学术诚信声明；
- 个人姓名或资料是否满足证书展示要求；
- 页面提示的是 `Claim`、`Show` 还是仍有未完成项目。

认证要求会随课程版本变化，因此应以对应认证页面显示的信息为准。参见 [近期认证领取示例](https://forum.freecodecamp.org/t/python-certification/788727)。

## 14. 推荐的学习节奏

每天可以安排 30～45 分钟：

```text
5分钟：复习上一次内容
20分钟：完成理论课或 Workshop
10分钟：完成一个小练习
5分钟：备份代码并写学习笔记
```

每学完一个模块，至少回答三个问题：

1. 这个知识解决什么问题？
2. 不看答案，我能否重新写一次？
3. 出现测试失败时，我能否解释失败原因？

不要只追求绿色勾选。真正掌握的标准是：关闭原来的代码后，仍然能够独立完成一个相似的小项目。

## 15. 最终验收清单

完成教程后逐项确认：

- [ ] 能打开 freeCodeCamp 学习页面；
- [ ] 已注册或登录固定账号；
- [ ] 能找到当前课程目录；
- [ ] 已选择一个适合自己的课程；
- [ ] 能识别任务说明、代码编辑器和测试区域；
- [ ] 已修改并运行一段代码；
- [ ] 所有测试均已通过；
- [ ] 已点击提交并继续；
- [ ] 返回课程目录后能看到完成标记；
- [ ] 已将重要代码备份到浏览器之外；
- [ ] 知道如何通过 `Get Help` 求助；
- [ ] 知道认证要求必须以当前课程版本为准。

全部项目均已确认后，说明你已经能够独立使用 freeCodeCamp 完成后续课程。
