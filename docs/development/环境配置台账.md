## 7. 已知风险与后续动作

1. Nacos 内存接近容器上限，新增 Java 服务前必须检查可用内存并按场景切换。
2. 虚拟机根分区只有 8.8GiB 可用，镜像、日志和备份必须限额；不得把 Elasticsearch 数据迁入该盘。
3. 虚拟机主机名仍为 `localhost`，正式服务注册前应设置稳定主机名并保留回滚记录。
4. 双 IPv4 地址共存；业务配置只能使用 `.10`，DHCP 租约变化不得影响服务地址。
5. 本机没有系统 Maven，创建后端工程时必须生成并验证 `mvnw`/`mvnw.cmd`。
6. Java 服务镜像尚未生成；完成模块后补充镜像、端口、堆内存、健康检查和 Nacos 注册实测。
