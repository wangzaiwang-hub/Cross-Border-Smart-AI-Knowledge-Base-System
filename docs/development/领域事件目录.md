# 领域事件目录

统一 Topic：`YGH_DOMAIN_EVENTS`。消息 Key 为 `eventId`，Tag 为事件类型；公共属性包含 `eventId/aggregateId/eventType/schemaVersion`。采用至少一次投递，消费者必须以 `eventId` 幂等。

| 事件 | 生产者 | 主要消费者 | 作用 |
|---|---|---|---|
| `ORDER_CREATED` | Order | Inventory/Notification | 订单已创建 |
| `ORDER_CANCELLED` | Order | Inventory/Notification | 释放库存、通知 |
| `ORDER_CLOSED` | Order | Inventory | 超时释放 |
| `ORDER_PAID` | Order | Notification | 支付成功通知 |
| `ORDER_REFUND_REQUESTED` | Order | Wallet | 发起模拟退款 |
| `ORDER_REFUNDED` | Order | Notification | 退款完成通知 |
| `WALLET_RECHARGE_SUCCEEDED` | Wallet | Notification | 虚拟充值完成 |
| `WALLET_PAYMENT_SUCCEEDED` | Wallet | Order | 订单转已支付、库存转已售 |
| `WALLET_REFUND_SUCCEEDED` | Wallet | Order | 订单转已退款 |
| `KNOWLEDGE_PUBLISHED` | Knowledge | Search/Notification | 建立全文及向量索引 |
| `KNOWLEDGE_UNPUBLISHED` | Knowledge | Search | 删除有效索引 |
| `TRAINING_ASSIGNED` | Training | Notification | 培训任务通知 |

Outbox 状态为 `PENDING → PROCESSING → PUBLISHED`；失败进入 `RETRY` 并指数退避，超过上限进入 `FAILED`。RocketMQ 消费失败返回重试，超过消费上限由 Broker 投递 `%DLQ%<consumerGroup>`。
