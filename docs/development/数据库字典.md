# 跨境智汇后端数据库字典

> 状态：实现冻结，集中迁移验证待执行。字段、索引、外键和约束的唯一机器可执行来源是各服务 `src/main/resources/db/migration/V*.sql`；本文用于架构评审和前端/运维交接，不替代 Flyway。

## 1. 数据库归属

| 数据库 | 引擎 | 所属服务 | 主要表 |
|---|---|---|---|
| `auth_db` | MySQL 8.4 | Auth | `auth_account`、`auth_credential`、`auth_refresh_token`、`auth_login_attempt`、`auth_password_reset`、`auth_account_admin_audit` |
| `user_db` | MySQL 8.4 | User | `user_profile`、`user_department`、`user_position`、`user_employee`、`user_employee_position`、`user_address` |
| `system_db` | MySQL 8.4 | System | `system_role`、`system_permission`、`system_role_permission`、`system_user_authorization`、`system_user_role`、`system_authorization_audit`、`system_dictionary_type`、`system_dictionary_item`、`system_setting`、`system_feature_flag`、`system_configuration_audit` |
| `product_db` | MySQL 8.4 | Product | `product_category`、`product_brand`、`product_spu`、`product_sku`、`product_specification`、`product_image`、`product_trace_event`、`product_batch`、`product_price_history`、`product_outbox`、`product_search_job` |
| `inventory_db` | MySQL 8.4 | Inventory | `inventory_stock`、`inventory_reservation`、`inventory_ledger`、`inventory_reconciliation` |
| `order_db` | MySQL 8.4 | Order | `order_cart_item`、`order_main`、`order_item`、`order_address_snapshot`、`order_state_history`、`order_outbox`、`order_inbox` 及审计/对账扩展表 |
| `wallet_db` | MySQL 8.4 | Wallet | `wallet_account`、`wallet_transaction`、`wallet_outbox`、`wallet_inbox` |
| `knowledge_db` | MySQL 8.4 | Knowledge | `knowledge_document`、`knowledge_chunk`、`knowledge_review`、`knowledge_index_job`、`knowledge_status_history`、`knowledge_tag`、`knowledge_document_tag`、`knowledge_document_version`、`knowledge_outbox` |
| `ai_db` | MySQL 8.4 | AI | `ai_conversation`、`ai_message`、`ai_citation`、`ai_tool_call`、`ai_prompt_config`、`ai_evaluation_case`、`ai_evaluation_run`、`ai_feedback`、`ai_rag_trace` |
| `training_db` | MySQL 8.4 | Training | `training_learning_path`、`training_course`、`training_path_course`、`training_chapter`、`training_document`、`training_gate`、`training_question`、`training_assignment`、`training_chapter_progress`、`training_quiz_attempt`、`training_weakness`、`training_outbox` |
| `notification_db` | MySQL 8.4 | Notification | `notification_template`、`notification_message`、`notification_dead_letter`、`notification_delivery_audit` |
| `search_db` | PostgreSQL 17 + PGVector | Search | `search_embedding`、`search_index_version`（Embedding 同步保留来源版本与更新时间） |

Nacos 自身使用独立 `nacos_config`；业务服务不得读取该库。Elasticsearch 保存可重建全文索引，不作为交易事实数据库。Admin 服务不拥有业务数据库，也不得跨库查询。

## 2. 核心字段与约束

| 领域 | 事实主键/业务唯一键 | 并发与幂等 | 敏感数据规则 |
|---|---|---|---|
| Auth | 账号 `id`；`principal` 唯一；Refresh `token_hash` 唯一 | Refresh 原子轮换；重置令牌 `FOR UPDATE` 后一次性消费 | 密码仅存 Argon2id；Refresh/Reset 仅存 SHA-256 摘要 |
| User | 用户 `user_id`；员工号、部门码、岗位码唯一 | 地址和组织实体使用 `version` | 地址只供本人或授权后台访问；订单复制地址快照 |
| Product | SKU `id` 与 `sku_code` 唯一；批次 `(sku_id,batch_no)` 唯一 | 商品、价格使用版本；Outbox 传播领域事件，`product_search_job` 可靠同步 ES | 溯源证明仅保存受控 URL/说明，不保存本机路径 |
| Inventory | `sku_id`；预留 `request_id` 唯一 | 条件更新保证非负；流水 `(request_id,movement_type)` 唯一 | 库存表是库存事实来源，Redis 不能替代 |
| Order | `order_no`、`(user_id,request_id)` 唯一 | 状态机、Inbox/Outbox、快照不可变 | 地址、商品、价格均使用下单快照 |
| Wallet | `user_id`；流水 `request_id` 唯一 | 余额与流水同一本地事务，余额 CHECK 非负 | 全部资金为模拟余额；金额使用 `DECIMAL(18,2)` |
| Knowledge | 文档 `id`；Chunk `(document_id,chunk_index)` 唯一 | 状态历史、版本、索引任务、Outbox | 文件使用 SHA-256、受控存储键和密级/可见性 |
| Search | `(document_id,chunk_id,index_version)` | 版本化索引和别名切换，可全量重建 | 仅接收已发布且有权知识；向量维度 1024 |
| AI | 会话/消息 `id`；反馈 `(user_id,message_id)` 唯一 | 引用、工具调用和 `ai_rag_trace` 绑定 Assistant 消息 | RAG 证据保存摘要与来源元数据；模型 Key 不入库 |
| Training | 路径/课程/任务 `id`；心跳 nonce、测验 `request_id` 防重 | 服务端累计有效时长、阅读位置并校验前置章节/关卡 | 员工仅能读取本人任务和被分配文档 |
| Notification | `(event_id,user_id)` 唯一 | 重试、死信、人工重放均审计 | 模板变量受限；日志不得记录重置令牌 |

## 3. 跨库边界

- 服务之间仅通过 `/api/v1/**`、`/internal/v1/**` 或领域事件交互，不建立跨数据库外键。
- `user_id`、`sku_id`、`order_id` 等跨域字段只是稳定 ID 引用，由拥有者服务解释。
- MySQL 保存业务事实；Redis 保存会话、限流和缓存；Elasticsearch/PGVector 保存可重建派生索引；RocketMQ 传递事件。
- Outbox 与本地业务写入同一事务，Inbox/业务唯一键负责至少一次投递下的幂等。
- `product_db` 通过 Flyway 固定初始化“粤港甄选商城/供港生鲜/岭南特产/跨境零食”类目，业务可在后台继续扩展树形类目。

## 4. 迁移与恢复

- 每个服务只执行自己的 Flyway 目录，迁移命名为 `V{n}__{description}.sql`，已发布迁移禁止修改校验和。
- 空库迁移、升级迁移、备份恢复和索引重建在集中测试阶段验证；恢复流程见《备份恢复与索引重建手册》。
- 生产账号分为迁移账号和应用账号；应用账号不授予 `CREATE/DROP/ALTER`，真实口令通过 Secret 注入。
