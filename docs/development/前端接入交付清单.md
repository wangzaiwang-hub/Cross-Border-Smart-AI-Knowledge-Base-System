# 前端接入交付清单

## 1. 通用协议

- 网关基地址：`http://<gateway>:8080`；业务接口统一 `/api/v1/**`。
- Bearer JWT：`Authorization: Bearer <accessToken>`。
- 响应：`code/message/data/traceId/timestamp`；ID 始终按字符串处理，金额使用十进制字符串，时间使用 ISO 8601 带时区格式。
- 客户端写请求携带 `X-Request-Id`；支付、充值、退款和订单创建的业务请求还必须使用稳定 `requestId`，重试不得重新生成。
- 401 时只允许执行一次 refresh；refresh 失败清理会话。403 不刷新 Token，直接展示无权限状态。429 按 `Retry-After` 退避。
- Swagger UI：各服务 `/swagger-ui.html`；OpenAPI：各服务 `/v3/api-docs`。

## 3. SSE 协议

`POST /api/v1/ai/chat/stream` 返回 `text/event-stream`，事件顺序为 `meta`、多个 `delta`、`citations`、`done`。客户端以 `messageId` 去重；断线后不得把不完整回答标记为完成，可退回普通问答接口重试。任何引用必须显示来源标题和片段，不把模型文本伪装成政策原文。

## 4. 上传约束

- 知识：PDF、DOCX、TXT、Markdown，最大 50 MiB。
- 培训资料：PDF、DOCX、TXT、Markdown，最大 50 MiB。
- 使用 `multipart/form-data`；不得把本地完整路径作为文件名提交。
- 415/校验错误时展示服务端 `message`，禁止前端自行改后缀绕过检测。

## 5. 模拟业务声明

充值、支付、退款、履约和物流均为模拟数据，不产生真实资金交易或真实发货。商城页面、个人中心、订单详情和管理后台必须持续展示该声明。
