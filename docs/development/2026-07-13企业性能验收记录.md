# 2026-07-13 企业性能验收记录

## 验收环境

- JDK 25.0.3 / Spring Boot 4.0.7 服务镜像。
- Windows Docker Desktop 约束开发环境，网关从 `http://localhost:8080` 对外服务。
- MySQL、Redis 和 Nacos 使用项目开发基础设施；按场景串行启动业务服务，避免低内存开发机产生资源争用。
- 压测器为 `grafana/k6:2.0.0`，使用真实验证码注册、Argon2 密码校验和 JWT 签发链路获取临时令牌。账号密码和令牌均未落盘。

## 结果

| 场景 | 负载 | 请求数 | 错误率 | P95 | 门禁 | 结果 |
|---|---:|---:|---:|---:|---:|---|
| 商品搜索 | 3 VU / 60s | 3,034 | 0% | 103.85ms | < 1,000ms | 通过 |
| 知识文档普通查询 | 5 VU / 60s | 7,488 | 0% | 93.84ms | < 500ms | 通过 |
| 钱包充值写入 | 1 req/s / 60s | 61 | 0% | 43.34ms | < 1,000ms | 通过 |

## 可复现方式

执行 `ygh-tests/ygh-performance-tests/k6/enterprise-api.js`，通过 `YGH_SCENARIO=query|write|search` 选择单一场景，通过 `YGH_GATEWAY_URL` 或 `YGH_BASE_URL` 注入网关地址，通过 `YGH_ACCESS_TOKEN` 注入专用压测账号的短期访问令牌。脚本对非 2xx 响应率设置 `<1%` 门禁。

本记录证明当前约束开发环境满足项目的开发验收阈值，不等价于生产容量规划；上线前仍需在目标服务器规格上执行容量、峰值和耐久性测试。
