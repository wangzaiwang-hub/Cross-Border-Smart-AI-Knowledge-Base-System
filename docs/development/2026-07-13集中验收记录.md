## 本轮运行时缺陷及修复

- Spring Boot 4 模块化自动配置下，AI、Search、Notification 缺少 `spring-boot-starter-flyway`，导致服务健康但业务表未迁移；已补齐并验证真实数据库迁移。
- Elasticsearch 开启安全认证而 Search 客户端未携带 Basic Auth；已统一安全客户端工厂并覆盖索引、检索、删除和版本切换。
- 培训 `MAX(score)` 在真实 MySQL 返回 `Number` 的具体类型与测试假设不一致；已改为 `Number.intValue()`。
- Docker Desktop 3GB 环境不能同时常驻 Elasticsearch、RocketMQ 和全部 Java 服务；已验证严格按平台、商城、AI、培训/通知场景互斥运行。
