# 权限矩阵与状态机

## 权限矩阵

| 能力 | USER | EMPLOYEE | ADMIN/运营权限 |
|---|---:|---:|---:|
| 浏览商品、维护本人地址、本人订单与钱包 | ✓ | ✓ | ✓ |
| 查询本人培训任务和提交学习记录 |  | ✓ | ✓ |
| 上传/审核/下线知识 |  | 按权限 | `ADMIN` |
| 课程、章节、题库和任务分配 |  | 按权限 | `training:course:write`、`training:assignment:create` |
| 部门、岗位和员工管理 |  |  | `organization:write`、`employee:write` |
| 查看全部订单 |  |  | `order:read:all` |
| 角色与授权关系 |  |  | `system:rbac:write` |

前端按钮隐藏只改善体验，后端签名用户上下文和权限校验是唯一授权依据。内部 `/internal/v1/**` 不经过用户授权，必须使用允许名单内服务身份的 HMAC 签名。

## 状态机

- 商品：`DRAFT → PUBLISHED → OFFLINE`；非 `PUBLISHED` 商品不能结算。
- 订单：`PENDING_PAYMENT → PAID → PROCESSING → COMPLETED`；待支付可到 `CANCELLED/CLOSED`；已支付可到 `REFUNDING → REFUNDED`。
- 库存预留：`LOCKED → SOLD` 或 `LOCKED → RELEASED`。
- 知识：`UPLOADED → SECURITY_CHECKED → PARSED → PENDING_REVIEW → PUBLISHED/REJECTED`；发布后可到 `OFFLINE/EXPIRED`。
- 培训：`ASSIGNED → IN_PROGRESS → COMPLETED`。章节按序解锁；有效时长达标且关卡通过后才允许下一章，前端不能直接提交完成状态。
