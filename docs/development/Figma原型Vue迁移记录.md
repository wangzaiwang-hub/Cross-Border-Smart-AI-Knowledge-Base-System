# Figma 原型 Vue 迁移记录

## 输入审计

`Design_System_SaaS_Landing_Page.zip` 是 Figma 导出的 React + TypeScript + Tailwind/shadcn 演示工程。其 `App.tsx` 将商城、后台和培训大量页面集中在单文件，并使用模拟账号、模拟权限和模拟业务数据，不符合本项目 Vue 3、真实 API、JWT/RBAC 和可维护模块化要求。

## 正式实现决策

- 保留原型的信息架构参考：商城、运营后台、AI 客服、知识治理和培训闯关。
- 不引入 React、shadcn 或原型模拟数据，正式工程使用 Vue 3 + TypeScript + Vite + Pinia + Vue Router + Element Plus。
- 原型的通用蓝色 SaaS 外观改为项目专属的“湾区绿、朱砂红、纸张米”设计体系，商城、后台与培训端共享品牌语言但保留不同信息密度。
- 所有功能页拆分为独立 Vue SFC 和 API 模块；路由由真实登录状态、角色和权限点守卫。
- 金额、ID、时间、错误码、SSE 和刷新令牌均使用后端契约，不在页面中伪造业务成功。

## 页面覆盖

- 消费者端：首页、商品列表/详情、知识中心/详情、AI 客服、注册/登录/重置密码、购物车、结算、订单、钱包、地址、通知。
- 员工培训端：任务、课程目录/详情、章节学习、测验、进度和薄弱知识点。
- 运营后台：总览、用户、组织、RBAC、商品、库存、订单、钱包、知识、AI、培训、通知、系统配置和审计安全。

原 ZIP 作为用户提供的设计输入保留在本地，不进入 Git 和生产构建链。
