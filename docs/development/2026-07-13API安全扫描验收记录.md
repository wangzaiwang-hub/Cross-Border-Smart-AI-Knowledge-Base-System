# 2026-07-13 API 安全扫描验收记录

## 扫描范围

- 工具：OWASP ZAP 稳定镜像的 `zap-api-scan.py`。
- 契约：`spec/openapi/auth-service-v1.json`，共导入 20 个 URL，扫描器共访问 69 个 URL。
- 链路：ZAP 容器 → Gateway `:8080` → Auth Service → Redis/MySQL。
- 执行时仅保留 Gateway 和 Auth，避免低内存开发环境资源争用。

## 结果

- 118 项规则通过，`FAIL-NEW=0`、`FAIL-INPROG=0`，即 P0/P1 安全缺陷为 0。
- SQL 注入、XSS、路径穿越、XXE、命令注入、服务端模板注入、Log4Shell、Spring4Shell、敏感信息泄漏等主要规则均通过。
- 扫描器报告 2 个 Low 级告警：一个是主动扫描异常请求触发的服务端错误，一个是 CORP 响应头。后者已在网关统一收紧为 `Cross-Origin-Resource-Policy: same-origin`，并增加自动化断言。

原始 HTML/JSON 报告是包含开发环境地址的临时运行产物，不进入 Git；本脱敏记录是仓库内的验收证据。
